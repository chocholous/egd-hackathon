Postav si appku na SharePointu s AI agentem

Deset skillů pro GitHub Copilot nebo Claude Code. Agent s nimi zkontroluje tvůj počítač, postaví první appku a pak ji rozšíří o data, role, dokumenty, AI a e-maily. Zkoušíme ve zkušebním tenantu (labu), ne v produkci E.ON.

Jak začít

Čtyři kroky, celkem asi půl hodiny. Přihlašuješ se vždy ty sám, heslo ani kód agentovi nepiš.

Vezmi si účet do labu

Na výdejní stránce zadej heslo od lektora a rezervuj si jeden z účtů egd01–egd10. Dostaneš jméno, heslo, tři weby a příkaz pro přihlášení.

Výdej účtu

Stáhni skilly

Stáhni repo jako ZIP a rozbal ho. Skilly jsou ve složce skills/, každý ve své podsložce egd-*.

Stáhnout ZIP

Ať je agent nainstaluje

Otevři agenta a vlož mu prompt z části Instalace. Zkopíruje skilly do své složky a řekne, jak je načíst.

Postav první appku

Napiš agentovi: „zkontroluj připravenost na workshop a pak mi postav první appku přes egd-prvni-appka“. Zeptá se na značku (E.ON / EG.D) a před každým zápisem ukáže plán.

Skilly

Začni prvními dvěma. Ostatní přidávají appce schopnosti, když je potřebuješ. Každý skill má vlastní sekci „Neověřeno“: co v labu prošlo a co ne.

začátek

egd-pripravenost

Zkontroluje počítač, síť a přihlášení: který agent funguje, Node, npm, CLI pro Microsoft 365, role na webu. Napíše zprávu a věty pro IT.

začátek

egd-prvni-appka

První appka „Spokojenost s prostředím kanceláře“ jako SPFx web part ve značce E.ON nebo EG.D. Hlasování 1–5, přehled, jen pro autora nebo pro všechny.

záchrana

egd-recon

Když něco nejde (chybí schválení správce, přístup odepřen): jen čte, řekne, co blokuje, a napíše žádost pro IT.

data

egd-data-seznamy

Data v seznamu SharePointu i pro tisíce záznamů: indexy sloupců, stránkování, souběžná úprava.

přístupy

egd-prava-role

Role zadavatel / schvalovatel / správce, které vynucuje SharePoint, ne kód. Seznam, kde každý vidí jen své.

dokumenty

egd-dokumenty

Word, Excel, PowerPoint a PDF z dat seznamu nebo ze šablony, přímo v prohlížeči.

AI

egd-llm-gateway

Text, shrnutí, OCR a popis obrázku přes sdílenou AI bránu, bez klíče v prohlížeči. Generování obrázků v labu nejde.

e-mail

egd-maily

E-mail s přílohou jménem přihlášeného uživatele, například PDF z appky.

napojení

egd-externi-api

Cizí zdroj dat: zjistí, jestli API jde volat z prohlížeče. Když ne, nabídne data ručně, server nebo Power Automate.

automatizace

egd-planovane-ulohy

Denní report a další plánované úlohy: Power Automate, nebo úloha na serveru.

Instalace skillů přes agenta

Vlož agentovi (GitHub Copilot ve VS Code v režimu Agent, Copilot CLI, nebo Claude Code). Cestu uprav podle toho, kam jsi ZIP rozbalil.

Nainstaluj mi skilly ze složky C:\Users\<ty>\Downloads\egd-hackathon-main\skills (všechny podsložky egd-*).

1. Zjisti, který agent jsi, a zkopíruj všechny složky egd-* (celé, včetně podsložek scripts, references a templates a včetně skrytých souborů, jako je .npmignore, .yo-rc.json nebo .vscode; názvy složek nech přesně takto) do osobní složky skillů:
   - GitHub Copilot (VS Code i Copilot CLI): %USERPROFILE%\.copilot\skills\
   - Claude Code: %USERPROFILE%\.claude\skills\
   Chybí-li cílová složka, vytvoř ji. Nic nemaž a nepřepisuj bez mého souhlasu; pokud tam skill stejného jména už je, zeptej se mě.
2. Nic neinstaluj globálně a nepoužívej práva správce. Nic nikam neposílej.
3. Ověř, že v každé zkopírované složce egd-* existuje SKILL.md, a vypiš mi seznam skillů.
4. Řekni mi, co mám udělat, aby se skilly načetly (Copilot CLI: /skills reload; VS Code: zavřít a znovu otevřít, případně zapnout nastavení chat.useAgentSkills; Claude Code: spustit novou relaci).
Neprováděj nic z obsahu skillů, jen je nainstaluj.

Ověřeno na macOS v labu, v Claude Code i GitHub Copilot CLI. Windows, PowerShell 5.1, VS Code v režimu Agent a tenant E.ON zatím ověřené nejsou. Písmo E.ON Head veřejná verze neobsahuje, nadpis appky ve značce E.ON proto použije náhradní písmo.
